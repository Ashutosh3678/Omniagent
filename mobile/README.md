# OmniAgent Mobile

Flutter UI for the eight OmniAgent screens. Mock data only — no backend,
AI, or remote PC control.

## Screens

- Welcome / Login
- Home
- Devices
- Task Execution
- Live Monitoring
- Task Result
- History
- Settings

Bottom tabs: **Home, Devices, History, Settings**. Execution, Live, and
Result open as stack screens.

## Run

```powershell
cd mobile
flutter pub get
flutter run
```

Web:

```powershell
flutter run -d chrome
```
